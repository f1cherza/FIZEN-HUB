# FIZEN HUB

Минималистичная личная панель: задачи, проекты, заметки, планировщик и инструменты разработчика.

## Запуск
1. Распакуй архив в отдельную папку.
2. Открой `index.html` в современном браузере.
3. Для более надёжного запуска можно использовать локальный сервер из папки проекта:
   - Python: `python -m http.server 8000`
   - затем открыть `http://localhost:8000`

## Сохранение и резервные копии
- Данные сохраняются в `localStorage` этого браузера.
- В разделе «Настройки и данные» нажми «Экспортировать JSON» для резервной копии.
- Импорт JSON заменяет текущие данные, поэтому сначала экспортируй текущую копию.
- Не очищай данные сайта/браузера, не сохранив резервную копию.
- Хранение локальное: данные не синхронизируются автоматически между устройствами и браузерами.

## Модули
- Обзор, задачи с приоритетом/сроками/проектами
- Проекты и прогресс выполнения
- Заметки с тегами и поиском
- Планировщик событий и дедлайнов
- JSON formatter/minifier, системы счисления, генератор паролей, HEX/RGB, Unix timestamp, кодовый блокнот
- Светлая/тёмная тема, акцентный цвет, импорт/экспорт, сброс данных

## Ограничения первой версии
- Календарь показывает список событий, а не сетку месяца.
- Напоминания не присылают уведомления, когда страница закрыта.
- Резервная копия — файл JSON; синхронизации с облаком пока нет.
